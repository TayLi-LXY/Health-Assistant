# 证据分级标准与评分规则

本系统参考 GRADE（Grading of Recommendations Assessment, Development and Evaluation）及牛津证据分级框架的核心思想，设计了一套简化的、可计算的证据分级模型，用于对知识库中检索到的健康信息进行自动化质量评估。

## 1. 分级标准定义

采用四级证据等级（Level 1–4），与证据强度由低到高对应：

| 等级 | 名称 | 证据强度 | 典型来源 |
|------|------|----------|----------|
| **Level 4** | HIGH | 高证据强度 | 顶级权威机构（如 WHO、CDC）发布的临床指南、系统综述 |
| **Level 3** | MEDIUM | 中等证据强度 | 知名医疗机构（如 Mayo Clinic）、大型研究机构发布的专业文章或研究摘要 |
| **Level 2** | LOW | 低证据强度 | 信誉良好的健康资讯网站、经过认证的医生撰写的科普文章 |
| **Level 1** | VERY_LOW | 极低证据强度/仅供参考 | 来源不明、缺乏作者信息或带有明显商业推广性质的内容 |

## 2. 评分规则

证据分数由三个维度综合计算：**来源权威性**、**内容时效性**、**文档类型**。

### 2.1 来源权威性（0–100 分）

基于 URL 域名及来源名称（source_name）进行白名单匹配，并赋予基础分值：

| 来源类型 | 域名示例 | 分值 |
|----------|----------|------|
| 顶级权威机构 | who.int, cdc.gov, nih.gov, cdc.gov.cn, nhc.gov.cn, gov.cn | 90–100 |
| 知名医疗机构 | mayoclinic.org, medlineplus.gov, clevelandclinic.org, harvard.edu | 82–88 |
| 国际健康资讯 | webmd.com, healthline.com | 70–75 |
| 信誉良好的中文健康资讯 | dxy.cn, baikemy.com, chunyuyisheng.com | 60–65 |
| 百科类 | wiki.cn, baike.baidu.com | 52–55 |
| 社区/论坛 | tieba.baidu.com | 35 |
| 默认/未知 | 其他 | 40 |

若 `source_name` 中含「世界卫生组织」「WHO」「CDC」「疾控」「梅奥」等关键词，会对对应域名分值进行向上修正。

### 2.2 内容时效性（0–100 分）

根据元数据中的 `publication_date` 计算发布距今天数，映射为时效性得分：

| 发布时间 | 得分 |
|----------|------|
| 近 1 年内 | 95 |
| 1–2 年 | 85 |
| 2–5 年 | 75 |
| 5 年以上 | max(60, 80 − 天数/365 × 2) |
| 无发布日期 | 70（默认） |

支持日期格式：`%Y-%m-%d`、`%Y/%m/%d`、`%Y-%m`、`%Y`。

### 2.3 文档类型（加分/减分）

优先使用元数据 `document_type` 直接映射；若无，则对 title + content 进行关键词匹配，取较高加分：

| 文档类型 | 元数据值 | 加分 |
|----------|----------|------|
| 临床指南 | guideline | +15 |
| 系统综述 | systematic_review | +12 |
| 荟萃分析 | meta_analysis | +12 |
| 临床试验 | clinical_trial | +10 |
| 官方发布 | official | +10 |
| 事实清单 | fact_sheet | +8 |
| 百科 | encyclopedia | +5 |
| 新闻 | news | +3 |
| 论坛帖 | forum_post | −5 |

## 3. 加权公式

综合得分计算公式：

```
总分 = 权威性 × 0.5 + 时效性 × 0.3 + min(文档类型加分, 20) × 0.2
```

- 权威性和时效性按 0–100 分计算
- 文档类型加分上限为 20，可为负值（如论坛帖）

## 4. 等级映射

根据总分将证据划分为四个等级：

| 总分区间 | 证据等级 |
|----------|----------|
| 总分 ≥ 90 | Level 4（高证据强度） |
| 80 ≤ 总分 < 90 | Level 3（中等证据强度） |
| 60 ≤ 总分 < 80 | Level 2（低证据强度） |
| 总分 < 60 | Level 1（极低证据强度/仅供参考） |

## 5. 可解释性

每条证据在计算完成后会生成 `level_explanation` 字段，格式示例：

```
证据等级 MEDIUM(Level 3): 来源权威性得分: 88/100 (域名: mayoclinic.org); 时效性得分: 95/100 (发布于 120 天前); 文档类型加分: +5 (元数据:encyclopedia)
```

用户可在前端点击证据卡片上的「?」按钮查看完整分级说明，了解该证据被评为当前等级的具体原因。
